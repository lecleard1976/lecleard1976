Jenkins is popular automation server. It supports SCM tools including Subversion and GitHub and others, and can execute Apache Ant and Apache Maven based projects, as well as arbitrary shell scripts and Windows batch commands. It can be used to implement automated processes supporting the concepts of both continuous integration and continuous delivery and has plugins are available for integration with most standard tools that support the development lifecycle.

Jenkins is available in Software as a Service (SaaS) format at no cost to DXC users. Included with this solution are standard jobs that extract code from version control, execute unit tests, build and delivery the output to a delivery repo. These jobs can be replicated for teams to quick start their project and online help is available so that they can easily be tailored for a specific project.
