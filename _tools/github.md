GitHub is a web-based Git repository hosting service. It offers all of the distributed revision control and source code management (SCM) functionality of Git as well as adding its own features. Unlike Git, which is strictly a command-line tool, GitHub provides a Web-based graphical interface and desktop. It also provides access control and wikis for every project.

Key features include:

- Leverages the Git de-centralised version control solution 
- Allows teams to easily setup both public and private Git repositories 
- Allows teams to create Organizations to group Git repositories 
- Supports simple issue tracking 
- Supports concept of social coding 
- Provides the ability to lock branches 

There are other instances of GitHub available to DXC, which are listed below as well as the criteria for usage:

- DXC Inner Source: Intended for use by projects that follow an "inner sourcing" development model intended to encourage innovation and collaboration across the company, so content is potentially visible across DXC based on setup. There are currently 2 GitHub instances available: 
 - [https://github.dxc.com](https://github.dxc.com/) is an AWS cloud hosted instance of GitHub, residing within the legacy CSC network. This is available for use at no cost for all DXC employees and is the go forward solution for DXC for inner source. 
 - [https://github.houston](https://github.houston.entsvcs.net/) is an on premise instance of GitHub, residing within the legacy ES network. This is available for use at no cost for all ES employees, contractors and customer users with a business partner agreement in place. It is not currently available to legacy CSC users. Note: It is expected that this will be merged into the dxc.com instance at some point in the future. 
- [DXC Public Open Source](https://github.com/dxc-technology): This is hosted on github.com and is used to host open source projects (projects MUST be vetted and approved by DXC Open Source Review Board). 
- [DXC Partner GitHub](https://partner-github.csc.com/): This is used by DXC projects that require access to work collaboratively with external partners and/or clients.
