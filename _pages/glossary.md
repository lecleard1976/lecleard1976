# A
 - AaaS - Automation as a Service
 - aaS - aaS' is an acronym for 'as a service', and refers to something being made available to a customer as a service.
 - AD&S - Architectural Design & Strategy
 - [AMEA](https://my.dxc.com/our-company/regions/asia--middle-east---africa.html) - DXC Region for Asia, Middle East, and Africa.
 - [AMI](http://docs.aws.amazon.com/AWSEC2/latest/UserGuide/AMIs.html) - Amazon Machine Image (AMI) provides the information required to launch an instance, which is a virtual server in the cloud
 - [Ansible](http://www.ansible.com/ ) - An agentless orchestration engine that can automate application and systems.
 - [ANZ](https://my.dxc.com/our-company/regions/australia-and-new-zealand.html) - DXC Region for Australia and New Zealand.
 - APA - Agile Process Automation (aka BPS LEAP)
 - [API](https://en.wikipedia.org/wiki/Application_programming_interface) - An application programming interface (API) is a set of subroutine definitions, protocols, and tools for building application software. In general terms, it is a set of clearly defined methods of communication between various software components.
 - [Atom](https://atom.io/ ) - Atom is a text editor that's modern, approachable, yet hackable to the core — a tool you can customize to do anything but also use productively without ever touching a config file. Commonly used to edit Markdown, with integrations for GitHub.
 - [AWS ProServe](https://aws.amazon.com/professional-services/) - AWS Professional Services organization is a global team of experts that can be, for a price, consulted regarding the AWS Cloud
 - [AWS](https://aws.amazon.com ) -  A cloud computing platform offering ready to use web services which are loosely coupled.
 - [AWSbox](http://awsbox.org/ ) -  A featherweight DYI PaaS on top of AWS cloud EC2 for deploying node apps.
 - [Azure](https://azure.microsoft.com/en-us/) - Microsoft's cloud computing platform. Microsoft Azure is an open, flexible, enterprise-grade cloud computing platform.

 - [BOOMI](https://boomi.com/) - Dell Boomi AtomSphere is an on-demand multi-tenant cloud integration platform for connecting cloud and on-premises applications and data.
 - [BPaaS](http://www.dummies.com/programming/cloud-computing/hybrid-cloud/what-is-business-process-as-a-service-bpaas-in-cloud-computing/) - Business Process as a Service — A complete business process is provided as a service - such as billing, HR, payroll, advertising, etc.
 - [BPS](https://whatwesell.dxc.com/dxc/offerings/business-process-services/) - Business Process Services, A DXC Offering Family.
 - [Bucket](https://aws.amazon.com/s3/) - A bucket is a logical unit of storage in Amazon Web Services (AWS) object storage service, Simple Storage Solution S3
 - [Buildathon](https://en.wikipedia.org/wiki/Hackathon) - A Buildathon is similar to a "hackathon", but without the connotation of hacking. (see hackathon).

The main characteristic of the DevOps movement is to strongly advocate automation and monitoring at all steps of software construction, from integration, testing, releasing to deployment and infrastructure management.

# X
 - XCDE - eXtensible Configuration Deployment Engine. Pronounced exceed, XCDE is the next generation of RTCE. Not only does it transport Configuration data but it also plays a significant role in the configuration of the PDXC phase 1 compartment tools. It is split into the XCDE Master and XCDE Satellite. The Master controls the triggers/requests for configuration changes and the Satellite receives the requests and communicates with the last mile tools to execute the commands. The standard PDXC tools integrated in this way are Nagios XI, LogStash and UCMDB/UD. In this way Monitoring deployment is automated based on CI data and discovered config data is transmitted to ServiceNow.
