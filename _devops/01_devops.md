DevOps is a culture that emphasizes the collaboration and communication between apps development and operations and the automation of software delivery and infrastructure changes. It aims at establishing a culture and environment where development, test and delivery happen rapidly, frequently, and more reliably.

## Overview

The EDGE Platform has various ways project teams can apply DevOps practices to delivery.  Using the DXC centrally managed repositories is the fastest way to increase DevOps maturity for ABS managed delivery teams.

Developers develop source code for an application in an IDE (ex. Visual Studio or Eclipse). The code is committed to Subversion or TFS and automatically compiled and unit tested via Continuous Integrations tools (Jenkins or TFS BE). The build is packaged using NuGet or Maven. The package is uploaded into the Nexus repository. Functional testing is automated through Unity. ALM and Agile Manager provide a central collaborative environment supporting integrated change management, configuration management traceability, test automation and monitoring dashboards.
