## Overview

This Test Automation portal provides guidance, suggestions and best practices that insure you are prepared to launch the automation testing base on your project's needs. There are many approaches to test automation during the production lifecycle, including Unit Testing, Integration Testing, Functional Testing and Performance Testing. These are described on the subsequent tabs. 

The Continuous Testing tab outlines the testing framework developed within DXC to support automating testing addressing all the testing phases.
