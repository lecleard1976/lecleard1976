"Code quality is a loose approximation of how long-term useful and long-term maintainable the code is." How to define code quality - [Quora](https://www.quora.com/How-do-you-define-code-quality)

## Overview

Code Quality is more than just executing formal tests or even unit tests. It is implementing a strategy to improve the quality of code in terms of maintainability, stability, efficiency and security. 

- Maintainability focuses on consistency of format and programming style, removing duplicate or redundant code, checking for complexity, etc., the intention is to make the code easier to maintain and reduce risks and costs of change. 
- Stability and efficiency focus on effectiveness of code by identifying potential common coding errors based on standard rules and the use of specific development techniques. 
- Security focuses on identifying potential security risks and vulnerabilities. 

The emphasis is to prevent defects occurring during the development of code, rather than the more traditional focus on defect detection during the later testing phases.

The information provided on the Code Quality portal provides guidance on standards, techniques and tools to help teams improve code quality.
