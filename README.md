This template site has been created specifically to provide an site that can be easily cloned and tailored for use by other teams. Our goal - to lower the bar for other teams to create their own GitHub pages...

The content of this site is described in more detail here. This page outlines what parts of the repo are part of the underlying theme and what is the content that is specific to the Global Tooling SMEs and can be updated/removed when tailoring for your own site. Refer to SME Central for the actual content for the team.

The content is almost identical to the [OurSite](https://github.dxc.com/pages/AET/OurSite/) site, but differs in that it uses a local copy of the Minimal Mistakes theme and this site has the Jenkins automation enabled to execute spell and link checking on each commit. Users can leverage either site for replication purposes, depending on their needs. This template site has the advantage of the quality checks being run via Jenkins, the other site uses a remote theme, so will automatically be upgraded as the theme is updated.

Instructions for replicating this site are available [here](https://github.dxc.com/pages/AET/GitHub_Pages_Template/tailor/).

**Warning**: Users can tailor the theme content, but caution should be taken. The theme supports cross platform access, i.e., PCs, phones, etc., using responsive HTML, so many of the underlying styles are designed to adjust display based on display format, etc. Changing styles can have unexpected consequences.
