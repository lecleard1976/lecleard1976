Containerization or application containerization extends the concept of virtualization, but is not synonymous with virtualization. 

Virtualization supports the ability to create multiple virtual machines (VMs) with their own OS and application layer within a single host server. This allows multiple virtual environments to run individually with different OS types and versions on a single hardware environment environment running it's own host OS. This reduces the overall cost of business, by maximizing the utilization of the physical environments.

Containerization further isolates the application from the host environment, so within a container you would only find the binaries, libraries, etc., required to run the application. A container runs within the OS of the host environment, which itself could be a server container, a virtual machine or a physical server. This allows a single physical server to host multiple virtual environments, which could be individual containers or virtual environments, which can themselves host multiple containers.
