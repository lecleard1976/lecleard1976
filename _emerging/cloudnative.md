*"Cloud Native applications amount to 'prescriptive software stacks' designed to work together for enterprises that are too busy to assemble components themselves, To get there, companies will build microservices - discrete application services - each running in its own container, then connect them via a network to build the application they want. Cloud native means 're-balancing the roadmap toward user-driven systems' that use standardized parts and follow standardized deployment and operational procedures"* Sam Ramji Cloud Foundry CEO

The cloud is dynamic and change is expected. To take advantage of change, we need to make change as low cost as possible and optimize for throughput by increasing the rate of change. We need to embrace new methods that lower the transactional cost of change, but that do not lower quality. It is very likely that the companies that embrace the cloud native patterns of software delivery will survive, those that don’t will struggle.

Traditionally, Enterprise Services skills have been focused on Cloud Hosted Development, the goal is to change this focus and complete the journey towards building more Cloud Native Applications.
